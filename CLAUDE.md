# CLAUDE.md

## Project Overview

GraphQL Subscriptions API built with Go, [gqlgen](https://github.com/99designs/gqlgen), Echo v5 router, and Redis pub/sub. Includes a TypeScript/React frontend client.

## Tech Stack

- **Language**: Go 1.26
- **GraphQL**: gqlgen v0.17.89
- **Router**: Echo v5
- **Pub/Sub**: Redis (go-redis/v9)
- **Frontend**: TypeScript / React (pnpm / Vite)
- **WebSocket**: graphql-ws
- **Container**: Docker / Docker Compose

## Project Structure

```
server.go              # Entry point
graph/                 # GraphQL schema, resolvers, generated code
internal/
  constants/           # Shared constants (e.g., server port)
  datastore/           # Redis client
  graphql/             # GraphQL server setup
  router/              # Echo router configuration
  service/             # Business logic
  testutil/            # Shared test helpers (mock Redis client)
frontend/              # TypeScript/React client application
```

## Build & Development

```bash
make help              # List all targets
make generate          # Generate GraphQL Go source code
make build             # Build the server binary
make run               # Build and run the server
make test              # Run tests
make coverage-check    # Run tests with coverage threshold
make static-check      # Generate, lint, and scan for vulnerabilities
make lint              # Run golangci-lint (includes gocritic, gosec) and hadolint
make trivy-fs          # Scan for CVEs, secrets, and misconfigurations
make ci                # Full local CI pipeline: deps, static-check, test, build
make ci-run            # Run GitHub Actions workflow locally via act
```

### Infrastructure

```bash
make redis-up          # Start Redis via Docker Compose
make redis-down        # Stop Redis
make image-build       # Build server Docker image
make frontend-image    # Build frontend Docker image
```

### Frontend

```bash
make frontend-build    # Install deps and build frontend
make frontend-run      # Build and start frontend
```

## Code Generation

GraphQL types and resolvers are generated by gqlgen. Configuration is in `gqlgen.yml`. After changing `.graphql` schema files, run `make generate`.

## Linting

- **Go**: golangci-lint v2 with gocritic, gosec, errorlint, bodyclose, goimports enabled (configured in `.golangci.yml`)
- **Dockerfiles**: hadolint (configured in `.hadolint.yaml`)
- **Security**: Trivy filesystem scan for CVEs, secrets, and misconfigurations

## CI

GitHub Actions workflow (`.github/workflows/ci.yml`) runs on push to `main`, tags, and PRs:

| Job | `needs:` | Steps |
|-----|----------|-------|
| **static-check** | — | Generate, Lint (golangci-lint + hadolint), Trivy scan |
| **build** | static-check | Build server binary |
| **test** | static-check | Test with coverage + upload artifact |
| **docker** | build (tags only) | Build Docker image, Build frontend Docker image |

Job graph: `static-check` → `build` + `test` (parallel) → `docker` (tags only).

A separate cleanup workflow (`.github/workflows/cleanup-runs.yml`) removes old workflow runs and stale caches weekly.
